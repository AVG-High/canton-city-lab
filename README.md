# Canton City Lab — New York online learning edition

A full-screen Manhattan entrance leads into a menu-driven learning workspace. Turn the mouse wheel to approach the skyline, continue onto the waterfront street, pass through the building threshold and arrive inside a quiet office. Nearby river and façade planes sweep outward during the approach, and a glass-door overlay opens into the office. This is a layered 2.5D design journey, not a reconstructed 3D city or a verified real institutional office. Every scene is derived from the same camera position, so reverse input returns through the route before workspace entry.

The entrance decodes the next image before advancing into it. Pending or failed scene images pause the camera before that transition; the explicit entry button and left-hand menus remain available to bypass the journey. The office remains visible for at least 650 ms before a 220 ms workspace fade, subject to completion, inactivity and touch-release checks. Reduced-motion mode bypasses camera movement and uses direct navigation. Keyboard and touch alternatives are retained. After entry, the sidebar changes the dashboard, lessons, role design and library; content scrolls inside its panel. Mobile has a direct entry and navigation drawer.

Included: four role perspectives, six interactive document-based lessons, per-browser progress/600 learning XP, profile/download and reference library. All learning and policy previews are **REFERENCE_ONLY**.

This website does not connect to the local Canton/Ganache processes and does not issue commands, authenticated role queries or ledger evidence. The role page explicitly states that the actual ledger server is not connected. It does not treat missing data as privacy success. No existing runtime, evidence, keys, tokens, logs, personal data or V1 mask images are part of the deployment. The local actual-ledger application and separately preserved V1 remain available.

The user requested a public website earlier in this conversation. This existing Site retains that audience and publishes only the educational frontend. Railway projects, databases and billing settings remain unchanged.

The Manhattan delivery is 3840×2160, resampled from a 1672×941 generated original; it is not native 4K detail. Its mobile delivery is 1440×810. The three new architectural scenes also have native 1672×941 sources, with 2560×1441 resampled desktop and 1280×720 reduced mobile JPEG delivery. The previous hero is retained as a panorama-load fallback. See ASSETS.md and docs/NEW_YORK_FLIGHT_ART.md for exact prompts, hashes and limits.
